## 📊 Data Description

### `step4_full_data.parquet`

This is the **core dataset** for the entire replication project. It contains cleaned and engineered features ready for machine learning.

#### Source
- **Raw Data**: CSMAR `TRD_Mnth` (Monthly Stock Returns)
- **Time Range**: 1997-01 to 2024-12
- **Total Observations**: 720,607 rows
- **Unique Stocks**: ~4,200 (varies by month)

#### Variables

| Column | Type | Description |
| :--- | :--- | :--- |
| `Stkcd` | string | Stock code (e.g., "000001") |
| `Trdmnt` | datetime | Trading month |
| `Mretwd` | float | Monthly return with cash dividend reinvestment |
| `Msmvttl` | float | Total market capitalization (in 1,000 RMB) |
| `CR_1` ~ `CR_12` | float | Cumulative returns over the past 1 to 12 months |
| `rNorm` | float | Cross-sectional normal score (target variable) |
| `Year` | int | Year extracted from `Trdmnt` |

#### Construction Steps

This file was generated by `scripts/01_preprocess.py`:

1. **Load Raw Data**: Read all CSMAR CSV files from `data/raw/`
2. **Clean Data**:
   - Remove missing returns
   - Remove extreme returns (< -90% or > 300%)
   - Remove missing/non-positive market cap
3. **Feature Engineering**:
   - Compute `CR_k` = cumulative return over past k months (k=1..12)
   - Shift forward by 1 month to avoid look-ahead bias
4. **Target Variable**:
   - Compute `rNorm` = normal score of monthly returns (cross-sectional)
   - `rNorm = Φ⁻¹(rank / (N + 1))`
5. **Save**: Export as Parquet format for efficient storage and loading
