## 📊 Data Format

Each `.npz` file is a compressed NumPy archive containing the following arrays:

| Key | Shape | dtype | Description |
| :--- | :--- | :--- | :--- |
| `y_pred` | (N,) | float32 | MLER predictions (normalized scores) |
| `y_true` | (N,) | float32 | Actual rNorm (target variable) |
| `months` | (N,) | object | Trading month (datetime64) for each observation |
| `stocks` | (N,) | object | Stock code (string) for each observation |

Where `N` = number of samples for that year (see table above).

### Variable Definitions

| Variable | Description |
| :--- | :--- |
| **y_pred (MLER)** | Machine Learning Expected Return. The model's forecast of the cross-sectional normal score (`rNorm`). Higher values indicate higher expected future returns. |
| **y_true (rNorm)** | Actual target variable. The cross-sectional normal score of the realized monthly return. |
| **months** | The calendar month for each observation (e.g., "2019-01"). |
| **stocks** | The stock code for each observation (e.g., "000001" for Ping An Bank). |

## 🚀 How to Use

### Load a Single Year

To load predictions for a specific year:

```python
import numpy as np

# Load predictions for 2019
data = np.load("data/predictions/ensemble_preds_2019.npz", allow_pickle=True)

y_pred = data['y_pred']       # MLER predictions
y_true = data['y_true']       # Actual rNorm
months = data['months']       # Trading months
stocks = data['stocks']       # Stock codes

print(f"Loaded {len(y_pred):,} predictions for 2019")
```

---

### Load All Years (Merge Locally)

To combine all annual files into a single merged dataset, use the following script. 
This is useful for running analysis across the entire 2015–2024 period.

```python
import numpy as np
import glob

# Load and merge all annual files
all_preds, all_trues, all_months, all_stocks = [], [], [], []

for f in sorted(glob.glob("data/predictions/ensemble_preds_*.npz")):
    data = np.load(f, allow_pickle=True)
    all_preds.append(data['y_pred'])
    all_trues.append(data['y_true'])
    all_months.append(data['months'])
    all_stocks.append(data['stocks'])
    print(f"Loaded {len(data['y_pred']):,} samples from {f}")

# Concatenate all years
y_pred_all = np.concatenate(all_preds)
y_true_all = np.concatenate(all_trues)
months_all = np.concatenate(all_months)
stocks_all = np.concatenate(all_stocks)

print(f"Total: {len(y_pred_all):,} samples (2015-2024)")

# Optional: Save the merged file locally
np.savez_compressed(
    "data/predictions/ensemble_predictions_merged.npz",
    y_pred=y_pred_all,
    y_true=y_true_all,
    months=months_all,
    stocks=stocks_all
)
print("✅ Merged file saved locally")
```

After running this script, you will have a single merged file:
`ensemble_predictions_merged.npz`

## 🔬 How These Files Were Generated

### Training Process

Each annual prediction file was generated using the following process:

1. **Expanding Window**: For year `Y`, the model was trained on all data from `TRAIN_START_YEAR` (1997) to `Y-1`
2. **CNN-LSTM Model**: The same architecture as described in the paper
3. **Ensemble**: 20 models with different random seeds
4. **Prediction**: Average of the 20 ensemble predictions

### Code Reference

```bash
# Generate all annual prediction files
python scripts/02_train_annual.py
```

## 📋 Validation

To verify the integrity of a prediction file:

```python
import numpy as np

def validate_file(filepath):
    """Check that a prediction file has valid data."""
    data = np.load(filepath, allow_pickle=True)
    
    required_keys = ['y_pred', 'y_true', 'months', 'stocks']
    for key in required_keys:
        if key not in data:
            print(f"❌ Missing key: {key}")
            return False
    
    # Check shapes
    n = len(data['y_pred'])
    assert len(data['y_true']) == n
    assert len(data['months']) == n
    assert len(data['stocks']) == n
    
    print(f"✅ Valid: {n:,} samples")
    return True

# Test
validate_file("data/predictions/ensemble_preds_2019.npz")
```

## ⚠️ Important Notes

1. **Memory Usage**: Loading all 10 years simultaneously requires ~2-3 GB of RAM
2. **File Sizes**: Each annual file is under 25 MB, well within GitHub's file size limit
3. **No Look-ahead Bias**: All predictions are truly out-of-sample:
   - Training data ends **before** the test year
   - No information from the test year is used in training
